HotelVagas — Plataforma de hospedagens

Aplicação web desenvolvida originalmente sob demanda de um cliente. O escopo desenvolvido está concluído; antes de disponibilizá-lo como demonstração pública, estou revisando segurança, dados e condições de publicação.

PHPLaravelVue.jsAplicação web
Situação atual · Em revisão para demonstração

A demonstração pública ainda não foi disponibilizada. Após a revisão de segurança e a confirmação dos direitos de publicação, pretendo oferecer um ambiente de testes com dados fictícios.

Contexto

Desenvolvi a aplicação sob demanda comercial para organizar informações de hospedagem e fluxos de consulta. O projeto não é apresentado como sistema implantado na operação do cliente, e sim como software sob encomenda com futura demonstração independente.

Funcionalidades descritas

O escopo documentado no currículo anterior abrange:

  • Cadastro e apresentação de informações de hotéis.
  • Consulta e listagem de hospedagens.
  • Perfis de usuário e controles de permissão.
  • Exportação de dados comerciais para planilhas.

Stack e organização

O projeto utiliza PHP, Laravel e Vue.js, conforme a documentação anterior. A próxima atualização deste estudo de caso apresentará estrutura de código, decisões técnicas e testes examinados, sem expor dados ou materiais de terceiros.

Etapa anterior à demonstração

  • Revisar autenticação, permissões e rotas expostas.
  • Inspecionar dependências, configuração de ambiente, logs e arquivos sensíveis.
  • Utilizar informações fictícias, sem dados reais de clientes ou empresas.
  • Validar condições contratuais e direitos de publicação do código, marca e conteúdo.
  • Publicar acesso demonstrativo somente após validação.
Transparência: este estudo de caso documenta o escopo e o estágio de preparação. A demonstração pública ainda não está disponível; o nome do projeto foi definido como HotelVagas.
